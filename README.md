# Smart Document Scanner with OCR

A university project for scanning documents, applying image processing, and extracting text using OCR.

## Features

- Upload images in JPG, JPEG, PNG formats
- Detect document edges and apply perspective transform
- Enhance scanned documents with grayscale, thresholding, and noise removal
- Extract text using Tesseract OCR
- Save resulting image, PDF, and extracted text

## Structure

- `docs/` - project documentation
- `images/` - sample images and assets
- `output/` - generated scanned images, PDFs, and text files
- `src/` - main source code package
- `gui/` - GUI components
- `processing/` - image processing modules
- `ocr/` - OCR integration
- `utils/` - helper utilities
- `tests/` - automated tests
- `main.py` - application entry point

## Setup

1. Create a virtual environment
2. Install dependencies
3. Run `main.py`
